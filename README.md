# מסע · המדריך האישי שלך בחו״ל

אב-טיפוס של אתר טיולים בעברית. המטייל כותב לאן הוא נוסע, לכמה ימים ומה מעניין אותו. האתר בונה לו מסלול הליכה ממקומות אמיתיים, ולכל מקום מצרף את הסיפור שלו, הערכת עומס לפי שעה והוראות הזמנה דרך האתר הרשמי.

**האתר באוויר:** https://shanymaderer-oss.github.io/Sm/

**עלות: 0 ₪.** כל השירותים חינמיים ולא צריך שרת.

## מה יש באתר

- **גלובוס תלת-ממדי** עם תמונות לוויין, שמסתובב לאט במסך הבית ונוחת לתוך מפת הרחובות של העיר.
- **הטיול מופיע מהר:** המסלול מוצג ברגע שהמקומות נבחרו, והסיפורים, התמונות ומסלולי ההליכה ממשיכים להיטען ברקע.
- **התמהיל המושלם**: כל הקטגוריות משתתפות, ומה שבחרתם מקבל את רוב היום. כל יום בנוי סביב מקום "חובה לראות" אחר, עם מסלול הליכה קצר. ארוחת צהריים וערב בכל יום (ועם אוכל גם ארוחת בוקר והפסקה מתוקה), מסעדות לפי איכות, תקציב ותזונה (צמחוני או כשר).
- **מלונות כמו בבוקינג**: מלונות מסודרים לפי ההתאמה למסלול, כוכבים ומחיר, עם קישור ישיר ל-Booking, Hotels.com, גוגל ו-Airbnb עם התאריכים ומספר המטיילים. בוחרים מלון והמסלול נבנה מחדש סביבו.
- **רחובות קניות מרכזיים**: בכל עיר מוצאים את הרחובות עם הכי הרבה חנויות אופנה, נעליים ומתנות על קטע הליכה אחד (מ-OpenStreetMap), עם מסלול הליכה לאורך הרחוב.
- **כמה הטיול יעלה**: הערכה לכל הטיול, לאדם וליום, בשקלים לפי שער היום: לינה, אוכל, כניסות, תחבורה ושונות. לכל מסעדה מחיר משוער לאדם, ולכל מלון מחיר משוער ללילה (לפי המחירים ב-Wikivoyage כשיש, אחרת לפי רמת המחיר והעיר).
- **תחבורה**: מכל שדה תעופה לעיר, כל האפשרויות עם זמן ומחיר, ומסומן מה הכי נוח, הכי זול והכי מהיר. בתוך העיר: איזה כרטיס לקנות, אילו אפליקציות מוניות עובדות, ובמסלול עצמו הערכה למונית כשתחנה רחוקה להליכה.
- **eSIM**: כמה עולה גלישה בחו״ל מול חבילה ישראלית, כמה GB צריך לטיול, ואיך מתקינים בלי לשלם בטעות על נדידה.
- **נגישות**: מסלול לכיסא גלגלים, עגלת תינוק או קושי בהליכה (מקומות נגישים, פחות הליכה, הצעה למונית), וגם טקסט גדול, ניגודיות גבוהה ובלי אנימציות.
- **מצב משפחתי**: שולחים את הטיול בוואטסאפ, כל אחד מסמן איפה היה ומוסיף הערות, וההערות מתאחדות כשמחזירים את הקישור.
- **זוכרים אותך**: מקומות שהייתם בהם מסומנים, והטיול הבא מעדיף מקומות חדשים ומטבחים שאהבתם. הבחירות האחרונות (תקציב, אוכל, נגישות) נשמרות לטיול הבא.
- **40 ערים מוכנות מראש**, כולל בטומי, טביליסי, לרנקה, לימסול, פאפוס, ניס, מינכן, דובאי, קרקוב ועוד.
- **מתווך לכל האתרים**: כרטיסים לאטרקציות (אתר רשמי, GetYourGuide, Tiqets), הזמנת שולחן (TheFork) וטיסות (Google Flights).
- **לפני שטסים**: תחזית מזג אוויר, ממיר מטבע לשקלים, מספרי חירום, שקעים, טיפים, מי ברז והפרש שעות.
- **חיפוש וקטגוריות כמו בגוגל מפות**: מסעדות, בתי קפה, קינוחים, שווקים, קניונים, ברים, אטרקציות, מוזיאונים ופארקים. לכל מקום: סוג מטבח, רמת מחיר, פתוח עכשיו, מרחק, טלפון, אתר וקישור לביקורות בגוגל.
- **דף לכל מקום**: תמונה והיסטוריה מוויקיפדיה, האזנה לסיפור, גרף עומס לפי שעה, שעות פתיחה, קישור לאתר הרשמי וניווט לתחנה הבאה.
- **"גם בסביבה"**: מקומות פחות מוכרים ליד כל תחנה, שאפשר להוסיף למסלול בלחיצה.
- **גלו עוד**: אוצרות נסתרים, דברים בחינם, משפטים שימושיים בשפה המקומית (עם השמעה) וטיפים.
- **מרכז הזמנות**: רשימת סימון לכל הזמנה, עם קישור לאתר הרשמי.
- **המיקום שלי**: נקודה כחולה על המפה (רק אחרי שהמשתמש מאשר).
- **הטיולים שלי**: טיולים נשמרים בדפדפן.
- **מדריך חכם (אופציונלי)**: צ׳אט, סיפורים בעברית, טיפים ומנות מקומיות, עם מפתח חינמי של Google Gemini.

## להעלות לאוויר ב-GitHub Pages (בחינם)

1. נכנסים ל-[github.com](https://github.com) ופותחים חשבון אם אין.
2. לוחצים על **New repository**, נותנים שם (למשל `masa`), בוחרים **Public** ולוחצים **Create repository**.
3. בדף של ה-repository לוחצים **uploading an existing file** וגוררים את **כל התוכן** של התיקייה (לא את התיקייה עצמה): `index.html`, `css`, `js`, `README.md`, `.nojekyll`.
4. לוחצים **Commit changes**.
5. עוברים ל-**Settings → Pages**. תחת **Branch** בוחרים `main` ו-`/ (root)` ולוחצים **Save**.
6. אחרי דקה-שתיים האתר עולה בכתובת `https://<שם-המשתמש>.github.io/masa/`.

## להריץ על המחשב

אפשר פשוט לפתוח את `index.html` בדפדפן. אם משהו לא נטען, מריצים מתוך התיקייה:

```
python3 -m http.server 8000
```

ונכנסים ל-`http://localhost:8000`.

## להפעיל את המדריך החכם (לא חובה)

1. נכנסים ל-[Google AI Studio](https://aistudio.google.com/apikey) ומוציאים מפתח (Create API key).
2. באתר לוחצים על גלגל השיניים ומדביקים את המפתח.

המפתח נשמר רק בדפדפן של מי שהדביק אותו. בשכבה החינמית Google עשויה להשתמש בשאלות לשיפור המודלים, ולכן לא כותבים למדריך פרטים אישיים. האתר בוחר לבד את מודל ה-Flash החדש ביותר שזמין למפתח.

## נתונים מוכנים מראש ל-20 ערים

פעולת GitHub (`.github/workflows/cities.yml`) מורידה פעם בשבוע את הנתונים של 20 ערים פופולריות לתיקייה `data/cities`, ולכן הטיול בערים האלה נבנה כמעט מיד. אפשר להריץ אותה ידנית בלשונית **Actions** ← **Refresh city data** ← **Run workflow**. כדי להוסיף עיר, מוסיפים שורה ב-`js/cities.js`.

## מה הלאה (רשימת עבודה)

### מחר: בדיקה ותיקונים
1. בדיקה בטלפון (שני) ובדיקה חיה באתר (Claude, צריך Chrome פתוח עם התוסף).
2. לוודא שנתוני 40 הערים ורחובות הקניות החדשים נאספו, ולבדוק את פריז שוב.
3. לאמת מחירי תחבורה משדות התעופה ב-32 הערים שעוד לא נבדקו מול מקור עדכני.

### שלב השותפויות והצמיחה
4. **דומיין משלנו** (בערך ₪40–60 לשנה). צריך החלטה של שני.
5. **קישורי שותפים**: Booking, GetYourGuide, ספקי eSIM, טיסות. ההרשמה דורשת פרטים אישיים ופרטי תשלום, ולכן שני נרשם/ת בעצמו/ה, ו-Claude מחבר את הקישורים לאתר.
6. **אפליקציה לטלפון (PWA)**: התקנה למסך הבית, ועבודה גם בלי אינטרנט.
7. **שרת קטן בחינם** (Cloudflare Workers): מדריך חכם בלי מפתח אישי, סנכרון משפחתי בזמן אמת, ושמירת משוב.
8. **עמודי ערים בעברית לגוגל**, למשל "מה לעשות ברומא ב-3 ימים", כדי שאנשים יגיעו מחיפוש.
9. **משוב ממשתמשים** ("היה מעולה" / "לא שווה") שהופך עם הזמן לדירוג משלנו.

### רעיונות לתכונות חדשות
- **שבת**: זמני כניסה ויציאה בעיר (Hebcal, חינם), תכנון שבת בהליכה ליד המלון, חב״ד ובתי כנסת.
- **מצב "עכשיו" בזמן הטיול**: מה הבא, האם פתוח, כמה ללכת, והחלפה למקום מקורה כשיורד גשם.
- **סיור קולי רציף**: הולכים, ובכל תחנה מתחיל הסיפור שלה.
- **הוצאות משותפות**: מי שילם מה ומי חייב למי, מול הערכת העלות של הטיול.
- **רשימת אריזה** לפי מזג האוויר, השקעים וסוג הטיול.
- **הופעות ואירועים** בתאריכי הטיול.
- **תזכורות**: "מחר צריך להזמין כרטיסים לקולוסיאום", "מחר גשם".
- **טיולי יום** מהעיר, עם איך מגיעים וכמה זה עולה.
- **בטיחות**: המלצות משרד החוץ, הקונסוליה הישראלית, תזכורת לביטוח נסיעות.

### כשמגדילים
- **ספק מפות ותמונות לוויין בתשלום** כשיש הרבה משתמשים או שימוש מסחרי.
- **אנגלית ושפות נוספות** אחרי שהגרסה בעברית יציבה.
